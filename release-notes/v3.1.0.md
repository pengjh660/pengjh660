# Claude Code Haha v3.1.0

这是一个围绕 **Windows 原生体验、持久化 PTY Shell、ConPTY 兼容性** 的版本。

相比 `v0.3.0`，本次完全重构了 Shell 执行模型：告别 `child_process.spawn()` 每次新建进程的方式，改用 `bun-pty` 持久化 PTY 会话。BashTool/PowerShellTool 现在共享一个常驻 shell 进程，cwd、环境变量、alias 在命令间保持。同时修复了 Windows 上 VT 序列不经过 ConPTY 导致终端控制异常的问题。

## Highlight

- **持久化 PTY 会话**：Shell exec 不再每次 spawn 新进程，通过 PtySession 维护常驻 PowerShell/bash 进程，状态（cwd、env、alias）跨命令保留。
- **Windows ConPTY 修复**：所有 VT 序列（alt screen、光标控制、颜色）改用 `process.stdout.write()`，修复 `writeSync(1, ...)` 绕过 ConPTY 的问题。
- **Tool prompt 更新**：BashTool / PowerShellTool 描述明确标注 shell 状态持久化，并加入 `TRAINING OVERRIDE` 段落对抗 AI 训练数据 bias。
- **工具 description 标注**：tool pick 列表显示 `(PERSISTENT session)` 标记。

## 主要更新

- PtySession 类：基于 marker string 的 exec 协议、exit code / cwd 提取、running guard、pending poll、health check。
- Shell exec() 新增 `usePty` 选项，BashTool 和 PowerShellTool 均传入 `usePty: true`。
- 全局单例 PTY 进程，首次使用时创建，进程退出时自动清理。
- 异常重启机制：PTY 进程崩溃后下次调用自动重建，调用方无感知。
- 7 项 PTY 集成测试覆盖：echo、cd 持久化、error cmdlet、native exit code、多行输出、abort 信号、空字符串。

## 问题修复

- 修复 Windows 下 alt screen 退出后终端内容丢失、闪烁的问题。
- 修复 `writeSync(1, ...)` 在 Bun/Windows 上绕过 ConPTY 导致 VT 序列不生效的问题。
- 修复 claude 命令解析到 C 盘 npm 旧包而非本地 build 的问题。
- 修复 .gitignore 未排除 `dist/` 和 bun build 缓存的问题。

## 验证

- `src/utils/Shell.test.ts` 7 项 PTY 测试全部通过。
- `src/ink/ink.tsx` 和 `src/ink/terminal.ts` 中的 VT 序列全部改为 `process.stdout.write()`。
- 在 Windows Terminal 中验证 alt screen 开关、Welcome 面板、logo 显示正常。

## 其他说明

- GitHub Release 正文继续以 `release-notes/v3.1.0.md` 作为来源。
- PTY 持久化在 Windows 上已验证通过；bash PTY 路径（非 Windows）已预留接口但尚未完整实测。
- 建议更新后使用 `$env:TEST_VAR = "hello"`（PowerShell 语法）而非 `set TEST_VAR=hello`（CMD 语法）验证持久化。
- 如果遇到终端显示异常，检查 `CLAUDE_CODE_NO_FLICKER` 环境变量（设 `1` 可禁用 alt screen）。
