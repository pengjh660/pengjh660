## 主要更新

### 1. 修复 Linux 上 Bash 工具全部返回 -1 的问题（PTY 兼容性）

Bash 工具默认使用 PTY 模式（持久会话），通过标记行 `__CLAUDE__<exitCode>|<cwd>|<marker>|__` 检测命令结束。

**根因**：标记搜索只匹配 `\r\n__CLAUDE__`（Windows/PowerShell 格式），但 Linux bash 启用 bracketed paste 模式后，实际输出前缀为 `\r`（不是 `\r\n`），标记永不匹配，所有命令超时返回 `exit code -1`。

**修复**（`src/utils/shell/ptySession.ts`）：
- `waitForMarker()` 同时搜索 `\r\n__CLAUDE__`（PowerShell）和 `\r__CLAUDE__`（Linux bash）
- 新增 `findActualMarker()`——遍历所有 `__CLAUDE__` 出现位置，跳过回显命令中的（前缀 `"`），匹配实际输出的（前缀 `\r` 或 `\n`），正确分离 stdout 和标记行

### 2. 质量验证

在 Linux x64 (bash 5.3) 上验证通过：
- 简单命令（true/false/echo/pwd）
- 管道（cat | head）
- 循环（for）
- 条件语句（[ ]、&&）
- 命令退出码（0/1/2/42）
- 文件不存在错误

12 项测试全部通过，出口码正确。
