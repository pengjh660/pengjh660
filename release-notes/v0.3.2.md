# Claude Code Haha v0.3.2

Windows 优化版，重点解决三个痛点：OpenAI 格式支持、SSE 碎片合并、终端选择。**本次新增 Linux (x64) 原生发行版**（单文件二进制 + 一键安装脚本）。

---

## 一键安装

### Windows

在 Windows PowerShell 中运行：

```powershell
powershell -c "irm https://github.com/pengjh660/pengjh660/releases/latest/download/install.ps1 | iex"
```

### Linux (x64)

```bash
curl -fsSL https://github.com/pengjh660/pengjh660/releases/download/v0.3.2/install.sh | bash
```

默认安装到 `~/.local/bin/claude-haha`，自动处理 PATH。运行时文件搜索需 `ripgrep`（`sudo apt install ripgrep`）；二进制自带 Bun runtime，无需安装 Bun / Node。

## 主要更新

### 1. 原生 OpenAI Chat Completions 支持

不再需要 CC Switch 中转。Claude Code 通过 fetch 拦截器（`openaiRouter.ts`）直接调用 OpenAI 兼容 API（DeepSeek、智谱 GLM 等），零额外组件。

配置方法：编辑 `~/.claude/settings.json`，在 `env` 块中添加：

```json
{
  "env": {
    "CLAUDE_CODE_OPENAI_CHAT": "1",
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/chat/completions",
    "ANTHROPIC_AUTH_TOKEN": "<your-api-key>"
  }
}
```

相关文件：`src/services/api/openaiRouter.ts`、`src/services/api/client.ts`

### 2. 修复 SSE 碎块文本

上游 proxy 返回的 SSE 文本被切成多个 `content_block_delta` 块时，Claude Code 不再显示碎片消息，自动合并为完整内容。对所有 provider 生效，无需配置。

相关文件：`src/services/api/claude.ts`（pendingText 累加器）

### 3. 跨平台原生终端（PowerShell / bash）

BashTool 可通过 `settings.json` 配置 `defaultShell`。Windows 直接调用原生 PowerShell，摆脱 Git Bash / WSL 依赖；Linux 使用 bash。

配置方法：

```json
{
  "defaultShell": "powershell"   // Windows；Linux 用 "bash"
}
```

相关文件：`src/utils/shell/resolveDefaultShell.ts`

### 4. 新增 Linux x64 发行版

- `bun build --compile` 编译的单文件二进制，自带 Bun runtime。
- 提供一键安装脚本 `install.sh`，支持远程 `curl | bash` 与本地安装。
- Linux 版使用系统 `ripgrep`，不需要 `rg.exe`。

构建方式（详见仓库 `Linux构建依赖清单.md`）：

```bash
bun install
bun build --compile --target=bun --outfile=dist/claude-haha src/entrypoints/cli.tsx
```

### 5. 资源文档

- 配置说明：`D:\documents\cladue\关键配置.md`
- Linux 构建指南：`D:\documents\cladue\Linux构建依赖清单.md`
